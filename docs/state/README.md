# Project state artefacts

Files in this folder carry decisions and progress between Claude Code sessions (Chapter 9).
They are written for humans first. Keep them short and current, and never put secrets,
credentials or personal data in them.

- `PLAN.md` – the approved plan for the current piece of work
- `progress.md` – what is done, what is next, open questions
- `decisions.md` – short log pointing to ADRs
